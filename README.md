# Santos Barbería — Landing page

Sitio web de **Santos Barbería**, barbería 100% familiar desde 1957 en Quetzaltenango y Mazatenango, Guatemala.

## Contenido
- `index.html` — la página completa (HTML, CSS y JavaScript en un solo archivo).
- `assets/fotos/` — fotografías del negocio.

Páginas: Inicio, Nosotros, Servicios, Sucursales, Galería, Productos, Reservar y Contacto.
Las reservas se envían por WhatsApp con el mensaje ya escrito.

## Ver en local
Abre `index.html` en el navegador, o sirve la carpeta:

```bash
python -m http.server 8000
```

## Publicar con GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)`.
